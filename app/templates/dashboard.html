⚠ ยังไม่ได้เปิด extended-statistics

ตัวเลข Query Types / Response Codes / Cache Sizes / DNSSEC บางตัวจะว่าง เพราะ unbound ปลายทางไม่ได้เก็บสถิติเพิ่ม

เพิ่มที่ /etc/unbound/unbound.conf ใต้บล็อก server: ของเครื่องที่รัน unbound

server:
    extended-statistics: yes

แล้วสั่ง sudo unbound-control reload หรือ sudo systemctl reload unbound
